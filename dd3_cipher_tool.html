6. Cipher guide

Vigenère (DD1)A letter-shifting method that uses a repeating keyword. The same keyword is needed to decrypt. DD1 messages in the supplied records begin with DD1:.
AES-256-GCM (DD2)A modern authenticated encryption method. It uses a 256-bit secret key and a unique nonce. It also checks message integrity. DD2 records use the wrapper DD2.MessageID.metadata.nonce.ciphertext.
Caesar CipherA simple substitution method that shifts each alphabet letter by a fixed number. The same shift is used in reverse to decrypt. It is included as the third cipher for comparison, not for strong security.
